# Kaede Typing

ブラウザだけで完結するタッチタイピング練習アプリ。日本語（ローマ字入力）と英語の両方を、
一人ひとりの苦手に合わせて出題しながら練習できます。

## 特徴

- **広告なし・課金なし・アカウント不要** — 登録もログインもありません
- **オフラインで動く** — 一度開けば通信なしで使えます（Service Worker）
- **日本語ローマ字対応** — `し` を `si` / `shi` のどちらで打っても正解になるオートマトン方式
- **適応カリキュラム** — 習得できた文字だけを見て、次の1文字を自動で解禁します
- **弱点の狙い撃ち** — 遅いキー・ミスの多い連接（つながり）を重点的に出題します
- **おとな / こども の2コース** — 同じエンジンで、見た目と進め方だけを変えています
- **目立たないモード** — 大人モードはエディタ・文書・表計算などに擬態し、既定で無音・無アニメ
- **データは端末内のみ** — 保存先はブラウザの localStorage だけ。外部には一切送りません
- **依存ゼロ** — npm パッケージも CDN も外部フォントも使っていません

## 使い方

### 1. GitHub Pages で開く

公開 URL はリポジトリの Pages 設定後にここへ追記します。`main` ブランチへの push で
`.github/workflows/pages.yml` が自動デプロイします。

### 2. ローカルで動かす

```sh
npm run serve
# → http://localhost:8080
```

ES Modules を使っているため、`index.html` を `file://` で直接開いても動きません。
かならず上記のローカルサーバ（依存ゼロの Node スクリプト）経由で開いてください。

### 3. 単一 HTML にまとめる

```sh
npm run build
# → dist/kaede-typing.html
```

CSS と JavaScript をすべて 1 枚の HTML に埋め込みます。こちらは **`file://` でそのまま開けます**。
USB メモリに入れて持ち運んだり、メールに添付したりできます（サーバも通信も不要）。
ビルドは `src/` と `assets/css/` の全ファイルが揃っている状態で実行してください。

## コース

### おとな

実務でそのまま役立つ練習に寄せています。メニューは「適応練習 / 弱点ドリル / 単語 / 文章 /
ビジネス文 / コード / 速度計測（60秒）」。画面は職場で目立たないよう低彩度・無音が既定で、
エディタ風・文書風・表計算風・メール風・ターミナル風などのスキンを切り替えられます。
`Esc` 2回、または `Ctrl+.` で即座に無害な画面へ切り替わり、もう一度押すと戻ります
（復帰時、計測は必ず一時停止した状態から再開します）。結果は WPM・正確率・一貫性を
落ち着いたカードで表示するだけで、派手な演出は出しません。

### こども

ひらがな中心の文言で、20以上のステージを進んでいく形式です。ステージ1〜6はホームポジション、
7〜12は上段、13〜16は下段、17〜20は総合。クリアすると正確率と速度に応じて★が1〜3つ付きます。
5ステージごとにボスバトル（制限時間内に HP を削る）、600打鍵ごとに仲間が1匹ふ化して図鑑に増え、
毎日3つのデイリーミッションがあります。効果音は既定でオン、長く続けると「ちょっと休もう」と
声をかけます。外部リンクも課金導線も一切ありません。

## 仕組み

- **適応解禁** — 解禁済みの文字の習熟度（速度と正確率を合わせた 0〜1 の値）が十分に上がると、
  次の1文字を解禁します。解禁順は「バランス重視」と「ホームポジション優先」から選べます。
- **弱点狙い撃ち** — キーごとの打鍵時間とミス率、さらに2文字の連接（bigram）の遅さを記録し、
  遅い組み合わせを含む語を優先的に出題します。
- **ローマ字オートマトン** — かなを状態機械で表現し、「次に受理できる文字の集合」を毎打鍵ごとに
  計算します。これにより `si`/`shi`、`ん`の `n`/`nn`、促音などの複数表記を、
  どれで打っても正解として扱えます。

詳しい設計の根拠は [docs/RESEARCH.md](docs/RESEARCH.md) にまとめています。

## プライバシー

- 通信は一切しません。解析・トラッキング・広告・外部フォント・外部画像のいずれも使っていません。
- 保存されるのはブラウザの localStorage だけで、端末の外に出ることはありません。
- 設定画面からデータの **書き出し（JSON）/ 読み込み / 全消去** ができます。
  localStorage が使えない環境でもアプリは落ちず、その回だけ記録されない状態で動きます。

## 開発

```
index.html                   シェル。CSS を5枚 link している
manifest.webmanifest         PWA マニフェスト
sw.js                        オフライン用 Service Worker
src/main.js                  エントリポイント
src/core/romaji.js           かな→ローマ字オートマトン
src/core/store.js            プロファイル永続化・統計・XP
src/core/curriculum.js       適応カリキュラム（解禁・重み付け）
src/core/generator.js        出題文の生成
src/core/engine.js           タイピング実行エンジン・計測
src/core/keyboard.js         画面キーボードと手の図
src/core/audio.js            WebAudio 合成の効果音
src/data/layouts.js          JIS / US 配列と運指
src/data/content.js          教材データの集約点（ja.js / en.js / code.js）
src/ui/shell.js              ルーター・ホーム・設定
src/ui/adult.js              大人モード
src/ui/kids.js               子供モード
src/ui/stats.js              統計画面
assets/css/                  base.css とビューごとの CSS
tools/                       サーバ・テスト・構文チェック・単一HTMLビルド
docs/ARCHITECTURE.md         実装契約（各モジュールの API）
```

```sh
npm test        # ローマ字エンジンとコアの単体テスト
npm run check   # 全 JS の構文チェック（実行はしない）
```

モジュール間の取り決めは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) が唯一の仕様書です。
API を変えるときは先にこちらを更新してください。
